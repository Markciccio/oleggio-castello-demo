# Oleggio Castello — demo del municipio

Una tappa dimostrativa con confronto fotografico 1973/oggi e immagine tracciata in WebAR. Il riferimento storico è una fotografia di una pagina fornita per la proposta; la didascalia riporta l'anno 1973. L'allineamento dei due punti di vista è regolabile.

Il sito include una vista comparativa che funziona anche senza fotocamera. La modalità AR usa il riconoscimento dell'immagine attuale del cortile e richiede un browser con accesso alla fotocamera.

Questa è una prova per la proposta al Comune, da calibrare sul posto. Guido è un personaggio illustrato su piano 2D.
